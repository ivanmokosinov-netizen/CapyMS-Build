CapyMS: сборка APK на GitHub без установки Android Studio

1. Распакуйте этот архив.
2. На github.com создайте репозиторий CapyMS-Build: Private; Add README включить.
3. В репозитории Add file > Upload files. Перетащите СОДЕРЖИМОЕ распакованной
   папки: папку .github, файл CapyMS_1.26_optimized.zip и README.txt.
   Не загружайте внешний ZIP целиком. Commit changes.
4. Откройте Actions > Build Android APK. Сборка запускается при загрузке файлов.
   Если не запустилась: Run workflow > Run workflow.
5. После зелёной галочки откройте запуск и скачайте Artifacts > CapyMS-APK.
6. Распакуйте полученный ZIP: внутри CapyMS.apk для телефона ARM64.

Это настройка автоматической сборки, НЕ уже собранный APK.
Workflow проверен структурно, но не запускался на GitHub в этой среде.
Первый запуск требует загрузки инструментов на сервер GitHub.
При ошибке пришлите красный шаг и его журнал; повторный запуск сам по себе
не исправляет ошибки кода. Возможны ограничения квоты GitHub Actions.
Сборка отладочная, не для публикации в магазине. Не требует ваших паролей/ключей.
Отладочный ключ кэшируется. При очистке кэша или переносе в другой репозиторий
подпись изменится. Не удаляйте старую игру без резервной копии прогресса.
Игра и ресурсы не публикуются наружу самим workflow: выбирайте Private.
